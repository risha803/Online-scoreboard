Онлайн-табло расписания междугородних рейсовых автобусов

Цель проекта: Адаптация табло для отображения расписания рейсов с учетом нашего часового пояса, позволяющая отслеживать отправление автобусов в режиме реального времени.

Технологический стек:
• Платформа: Node.js
• Фреймворк: Express

• Библиотеки:
  • ws: библиотека для работы с WebSocket в Node.js
  • Luxon: библиотека для работы с датами и временем
  • nodemon: утилита для автоматической перезагрузки сервера при изменениях в коде

▎Frontend:
• Технологии: JavaScript, Bootstrap 5.3.5, HTML

Проект включает в себя как серверную, так и клиентскую части, обеспечивая интерактивное и удобное взаимодействие пользователей с системой расписания. 
С помощью WebSocket реализована возможность обновления информации о рейсах в реальном времени, что позволяет пользователям всегда быть в курсе актуального расписания отправлений. 

Luxon используется для корректной обработки временных данных, учитывая часовой пояс, что позволяет избежать путаницы с временем отправления. 

С использованием Bootstrap обеспечивается современный и адаптивный интерфейс, который делает взаимодействие с табло простым и интуитивно понятным.
